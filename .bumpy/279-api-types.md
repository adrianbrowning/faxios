Breaking: `toFormData`'s `options` argument is now typed `FormSerializerOptions`, so TypeScript rejects an unknown or wrongly typed serializer option that it accepted before (the runtime is unchanged). `toFormData` now accepts the global `FormData` (and any FormData-like object with an `append` method) without a cast, returns `FormData` when no target is passed, and returns the target's own type otherwise. Every request API, including the `Faxios` class, its method aliases and `faxios(url)`, accepts a `URL` instance wherever it takes a URL; `faxios(url)` and the aliases now also send to it at runtime. The `Faxios` class overloads now reject an explicit response generic that disagrees with `responseSchema`, as the `faxios` instance already did. `FaxiosProgressEvent`, `GenericAbortSignal`, `GenericFormData`, `FaxiosRequestTransformer`, `FaxiosResponseTransformer`, `FaxiosBasicCredentials`, `ParamsSerializerOptions`, `CustomParamsSerializer`, `FormSerializerOptions`, `FaxiosDefaults`, `FaxiosPluginSpec` and `TransitionalOptions` are exported from the package root. The upload-progress docs now say why `onUploadProgress` isn't called in Deno and Bun.
