"@gcmdev/faxios": minor
---

Breaking: request methods on the instance and the `Faxios` class take `<T, D>` and always resolve to `FaxiosResponse<T, D>`; the third `R` type parameter is removed, so `faxios.get<User, string>()` now types `D` and a non-`FaxiosResponse` result is a type error. `RawFaxiosRequestConfig` is removed (use `FaxiosRequestConfig`). `FaxiosLike`, the instance shape `define()` and `route()` take, is still exported from the package root but is marked `@internal`: don't rely on it. The public `mergeConfig` takes `FaxiosDefaults | FaxiosRequestConfig` and a `FaxiosRequestConfig` and returns a `FaxiosRequestConfig` without an open index signature, so a misspelt key or wrong value type is a type error. `FaxiosHeaders` (constructor, `set`, `from`, `concat`) and the `headers` config option accept a `Headers`, a `Map` or an array of `[name, value]` pairs, and header values must be header values: `set("X-A", { nested: 1 })` and `set({ ... }, () => true)` are type errors. `fetchOptions` is the new `FaxiosFetchOptions` type: standard `RequestInit` keys are checked (`{ cache: 42 }` is a type error) while runtime extensions such as `dispatcher`, `next` and `cf` still pass. `FaxiosError.code` is `FaxiosErrorCode | (string & {})`, with the new exported `FaxiosErrorCode` union of the code statics on `FaxiosError`. `HttpStatusCode` has literal types (`HttpStatusCode.NotFound` is `404`) and a typed reverse lookup (`HttpStatusCode[404]` is `"NotFound"`). `all()` is typed like `Promise.all`, `spread()` keeps its callback's parameter and return types, and `formToJSON()` returns `null | Record<string, unknown>`. The published declarations no longer name DOM-only types, so a Node-only project (`lib: ["ES2023"]`, `types: ["node"]`, `skipLibCheck: false`) type-checks them; web types such as `Request`, `URL` and `RequestInit` resolve to the project's own globals when it declares them. Every optional config field and header also takes `undefined`, so `{ timeout: maybeNumber }` and `headers: { Authorization: undefined }` compile under `exactOptionalPropertyTypes`.
