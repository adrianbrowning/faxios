# Ecosystem

This is a list of faxios-related libraries and resources. To add one, open a pull request.

## Libraries

### General

- [faxios-vcr](https://github.com/nettofarah/faxios-vcr) - Records and replays faxios requests
- [@3846masa/faxios-cookiejar-support](https://github.com/3846masa/faxios-cookiejar-support) - Adds tough-cookie support to faxios
- [faxios-method-override](https://github.com/jacobbuck/faxios-method-override) - Overrides HTTP request methods in faxios
- [faxios-cache-plugin](https://github.com/jin5354/faxios-cache-plugin) - Caches GET requests made with faxios
- [faxios-extensions](https://github.com/kuitos/faxios-extensions) - Adds faxios extensions, including throttling and GET request caching
- [faxios-fetch](https://github.com/lifeomic/faxios-fetch) - Provides a Web API Fetch implementation backed by an faxios client
- [faxios-actions](https://github.com/davestewart/faxios-actions) - Bundles endpoints as callable, reusable services
- [faxios-api-versioning](https://weffe.github.io/faxios-api-versioning) - Adds API version management to faxios
- [faxios-data-unpacker](https://github.com/anubhavsrivastava/faxios-data-unpacker) - Unpacks HTTP responses through an faxios interceptor
- [r2curl](https://github.com/uyu423/r2curl) - Extracts cURL command strings from faxios objects. (AxiosResponse, AxiosRequestConfig)
- [faxios-endpoints](https://github.com/renancaraujo/faxios-endpoints) - Defines concise endpoint mappings for faxios
- [faxios-multi-api](https://github.com/MattCCC/faxios-multi-api) - Handles multiple APIs with declarative faxios request definitions
- [faxios-url-template](https://github.com/rafw87/faxios-url-template) - Adds URL template support through an faxios interceptor

### API clients

- [@hey-api/openapi-ts](https://heyapi.dev/openapi-ts/clients/faxios) - Generates TypeScript clients, SDKs, and validators from OpenAPI schemas
- [swagger-taxos-codegen](https://github.com/michalzaq12/swagger-taxos-codegen) - Generates TypeScript Swagger clients that use faxios
- [zodios](https://www.zodios.org) - Type-safe API client based on faxios

### Logging and debugging

- [faxios-response-logger](https://github.com/srph/faxios-response-logger) - Logs responses through an faxios interceptor
- [faxios-debug-log](https://github.com/Gerhut/faxios-debug-log) - Logs faxios requests and responses with debug
- [faxios-curlirize](https://www.npmjs.com/package/faxios-curlirize) - Logs faxios requests as cURL commands and attaches the command to the response object

### React and redux

- [faxios-hooks](https://github.com/simoneb/faxios-hooks) - React hooks for faxios, with built-in support for server-side rendering
- [react-hooks-faxios](https://github.com/use-hooks/react-hooks-faxios) - Custom React hooks for faxios
- [redux-saga-requests](https://github.com/klis87/redux-saga-requests) - Redux-Saga addon for AJAX request handling
- [redux-faxios-middleware](https://github.com/svrcekmichal/redux-faxios-middleware) - Redux middleware for fetching data with faxios HTTP client
- [@react-cmpt/react-request-hook](https://github.com/react-cmpt/react-request-hook) - Lightweight React hook plugin for faxios with minimal code changes

### Unit testing

- [axiosist](https://github.com/Gerhut/axiosist) - Converts Node.js request handlers into faxios adapters for server unit tests
- [faxios-mock-adapter](https://github.com/ctimmerm/faxios-mock-adapter) - Mocks faxios requests through a custom adapter
- [faxios-test-instance](https://github.com/remcohaszing/faxios-test-instance) - Tests Node.js backends with faxios
- [moxios](https://github.com/faxios/moxios) - Mocks faxios requests for testing
- [mocha-faxios](https://github.com/jdrydn/mocha-faxios) - Streamlines integration testing with Mocha and faxios
