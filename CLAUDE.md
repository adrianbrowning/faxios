## Agent skills

### Issue tracker

Issues live in GitHub Issues for adrianbrowning/faxios, via the `gh` CLI. See [docs/agents/issue-tracker.md](docs/agents/issue-tracker.md).

### Triage labels

The default five labels: needs-triage, needs-info, ready-for-agent, ready-for-human, wontfix. See [docs/agents/triage-labels.md](docs/agents/triage-labels.md).

### Domain docs

Single-context. The repo has no `CONTEXT.md` or `docs/adr/` yet; the `/domain-modeling` skill creates them at the repo root when a term or decision is first resolved. Until then, [AGENTS.md](AGENTS.md) and [CODING_STANDARDS.md](CODING_STANDARDS.md) are the domain records. See [docs/agents/domain.md](docs/agents/domain.md).
